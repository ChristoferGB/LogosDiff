# LogosDiff

**LogosDiff** is a modern Bible reading and study application focused on comparing different Scripture versions, organizing notes, and delivering a personalized user experience.

> *"Logos" means "Word" — here, you can explore it in depth.*

---

## 🙌 Inspiration

This project was inspired by the need for a simple, modern, and powerful Bible study tool — one that combines technology with purpose.

---

## ✨ Features

* 📚 **Multiple Bible Versions**
  Select and read different Bible translations.

* 🔍 **Advanced Search**
  Search biblical text with filters by book, chapter, verse, and content.

* 🔀 **Version Comparison**

  * Compare multiple versions for a single verse
  * Compare entire passages side by side

* ⭐ **Favorite Verses**
  Save and organize your favorite verses.

* 📝 **Personal Notes**
  Add notes to verses for deeper study and reflection.

* 🔐 **User Authentication**
  Login system to keep your data secure and personalized.

## 🛠️ Getting Started

### Prerequisites

* Docker
* Node.js
* .NET SDK 10

### 🔽 Clone the repository

```bash
git clone https://github.com/christofergb/logosdiff.git
cd logosdiff
```

### ▶️ Run with Docker

```bash
docker-compose up --build
```

### 💻 Run locally (without Docker)

#### Backend

```bash
cd backend
dotnet restore
dotnet run
```

#### Frontend

```bash
cd frontend
npm install
npm run dev
```
